# assets/
> L2 | 父级: `/CLAUDE.md`

Web 静态视觉资源域：集中声明全局样式、主题基础、可导出本地字体和长图文模板原始设计资产；组件通过构建器 URL 引用图片，避免临时远程链接进入产品代码。

## 成员清单

`index.css`: 全局样式入口，加载 Tailwind、主题 token、基础字体及长图文本地字体。
`fonts/`: 字体资源，包含古朴/绿意正文使用的鼎猎宋体，以及取自 Google Fonts 官方字形并以 WOFF2 压缩的文学标题站酷庆科黄油体。
`images/`: 图片资源，包含应用图标、长图文纹理、引用符号、封面线条和装饰切图。
`less/`: 公众号预览与编辑器使用的 Less 主题资源。
`example/`: 编辑器初始示例内容和演示素材。
